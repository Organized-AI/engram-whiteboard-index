# Engram Whiteboard Index

A one-page whiteboard walkthrough of memory hierarchy and Engram conditional memory, served as static assets from a Cloudflare Worker.

- Page: [public/index.html](public/index.html)
- Worker: [src/index.js](src/index.js), config in [wrangler.toml](wrangler.toml)

Deploy with `npx wrangler deploy`.
